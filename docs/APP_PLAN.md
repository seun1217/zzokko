# 쪼꼬 앱 — 기능 제안 & 개발 계획

> 임신 확인부터 출산, 신생아 초기까지 — 쪼꼬와 관련된 모든 것을 부부가 함께 기록하고
> 준비하는 앱.

## 1. 컨셉

- **한 줄 정의**: "쪼꼬의 첫 앨범이자, 예비 엄마·아빠의 비서"
- **사용자**: 예비 아빠(주 개발자·사용자) + 예비 엄마, 2인 공유가 기본 단위.
  나중에 조부모 '보기 전용' 초대 확장.
- **핵심 가치**
  1. 지금 뭘 해야 하는지 알려준다 (검진·행정·준비물 → 캘린더 데이터 재사용)
  2. 쪼꼬의 순간을 기록한다 (초음파, 태동, 태담 일기)
  3. 함께 결정한다 (이름 후보 투표, 체크리스트 분담)

## 2. 기능 제안

### MVP (Phase 1) — "지금 당장 쓸 수 있는 것"

| 기능 | 설명 |
|---|---|
| 🗓 D-day & 주수 트래커 | 홈 화면에 "오늘 쪼꼬는 12주 3일, D-193". 예정일(2027-03-17) 기준 자동 계산 |
| 🍓 주차별 발달 정보 | "이번 주 쪼꼬는 블루베리만 해요" — 주차별 크기 비유, 발달 포인트, 엄마 몸 변화, 아빠 할 일 팁 |
| ✅ 일정 체크리스트 | 이 저장소의 캘린더 데이터(검진·행정·준비물 44개)를 앱 내 체크리스트로. 완료 체크, 다가오는 일정 푸시 알림, .ics 내보내기 |
| 📸 초음파 앨범 | 검진마다 초음파 사진 업로드 + 주수·GS 크기·메모 태깅. 시간순 타임라인 뷰 |
| 💬 태담 일기 | 쪼꼬에게 쓰는 짧은 편지/일기. 아빠·엄마 각자 작성, 서로 공개. 나중에 아이에게 선물할 수 있는 기록 |

### Phase 2 — "태교 & 작명"

| 기능 | 설명 |
|---|---|
| ✍️ 작명 도우미 | 이름 후보 등록 → 부부 각자 별점/투표 → 랭킹. 항목별 체크: 발음(성+이름 읽어보기), 한자 후보와 의미, 영문 표기, 이니셜 조합, 돌림자, 흔한 이름 여부. 최종 확정 시 '쪼꼬 → 본명' 전환 이벤트 🎉 |
| 🎵 태교 음악 | 시기별 추천 플레이리스트(클래식/자장가/자연음). Spotify 연동으로 재생, 재생 기록 남기기 |
| 🗣 아빠 목소리 태담 | 태담 스크립트(동화·편지) 제공 + 아빠 목소리 녹음/보관. 저주파 목소리가 태아에게 잘 들린다는 포인트로 아빠 참여 유도 |
| 🦶 태동 카운터 | 28주~ 하루 10회 태동 체크 위젯. 시간대별 패턴 그래프 |
| 📊 엄마 건강 기록 | 몸무게, 혈압, 증상(입덧·부종 등) 기록. 검진 때 의사에게 보여줄 요약 뷰 |
| 💰 지원금·가계부 | 국민행복카드 바우처 잔액 메모, 정부 혜택 신청 현황 추적, 출산 준비 지출 기록 |

### Phase 3 — "출산 & 신생아 모드"

| 기능 | 설명 |
|---|---|
| ⏱ 진통 타이머 | 진통 시작/끝 탭 → 간격·지속시간 자동 계산, 5-1-1 규칙 도달 시 "병원 갈 시간" 알림 |
| 🧳 출산가방 체크리스트 | 산모/아기/아빠 짐 목록, 체크 상태 부부 실시간 공유 |
| 👶 신생아 모드 전환 | 출산일 입력 시 홈이 "생후 N일"로 전환. 수유·수면·기저귀 기록, 예방접종 스케줄(BCG, B형간염…) 자동 생성 |
| 📱 성장 앨범 | 초음파 앨범이 성장 앨범으로 이어짐. 월별 사진, 키/몸무게 성장 곡선 |
| 👴 가족 공유 | 조부모 초대(보기 전용) — 앨범·소식만 공개, 건강 기록은 비공개 |

## 3. 기술 스택 제안

**추천: PWA 우선 (옵션 A)**

| | 옵션 A — Next.js PWA (추천) | 옵션 B — Expo React Native |
|---|---|---|
| 스택 | Next.js + TypeScript + Tailwind, Supabase(인증·DB·스토리지·실시간) | Expo + TypeScript, Supabase 동일 |
| 배포 | Vercel, 홈 화면에 추가로 앱처럼 사용 | 앱스토어/플레이스토어 심사 필요 |
| 푸시 알림 | Web Push (iOS도 홈 화면 추가 시 지원) | 네이티브 푸시 |
| 적합한 이유 | 사용자 2명, 심사 없이 즉시 배포·수정, 개발 속도 최우선 | 녹음·위젯 등 네이티브 기능 강화 시 |

시작은 **옵션 A**로 하고, Phase 2의 녹음 기능이나 홈 위젯이 아쉬워지면 같은
Supabase 백엔드를 재사용해 Expo 앱을 추가하는 전략.

## 4. 데이터 모델 초안

```
users        (id, name, role: mom|dad|viewer)
pregnancy    (id, nickname "쪼꼬", edd 2027-03-17, birth_date nullable)
tasks        (id, date, title, description, category, done_by, done_at)   ← ics 데이터 시드
journal      (id, author_id, date, body, photo_urls[])
ultrasounds  (id, date, week, gs_size, photo_url, memo)
names        (id, hangul, hanja, meaning, romanized, proposed_by, status)
name_votes   (name_id, user_id, score 1~5, comment)
kicks        (id, started_at, count, duration)
health_logs  (id, date, weight, bp, symptoms[])
labor_timer  (id, start_at, end_at)         ← Phase 3
baby_logs    (id, type: feed|sleep|diaper, at, memo)  ← Phase 3
```

- 민감정보 원칙: **주민등록번호·진료기록 원본은 저장하지 않는다.**
  사진·건강 기록은 비공개 버킷 + 부부 계정에만 접근 허용(RLS).
